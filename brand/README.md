# Seamline Brand & Logo Kit

Built to match Seamline's exact web and scientific palette (`style.css` / `satellite-intro.css`): deep orbital slate `#0b1218`, MODIS solar amber `#ecbe62`, ember contrast `#dc8f72`, VIIRS cyan-teal `#58bdb8` / `#0e6b6f`, warm archival paper `#f3f2ee`, and bundled **Schibsted Grotesk** + **Instrument Sans** typography.

## Which file to use where

| Use Case | Recommended File(s) | Notes |
|---|---|---|
| **NASA Space Apps Team Profile** | `spaceapps-team-avatar-1024.png` | `1024x1024` dark badge with generous safe inset for circular avatar cropping |
| **GitHub Repository Avatar / Org** | `github-avatar-512.png` | `512x512` crisp circular-safe icon |
| **GitHub Social Preview & README Hero** | `seamline-github-banner-1280x640.png` | Exact `1280x640` GitHub Settings -> Social Preview size + top of `README.md` |
| **Website / Webapp Favicon** | `seamline-mark.svg` | Crisp `32x32` vector mark with automatic light/dark `prefers-color-scheme` colors |
| **Website Navbar / Header** | `seamline-lockup-light.svg` or `seamline-lockup-dark.svg` | Infinitely sharp standalone SVG lockups |
| **330-Second Video Intro / Outro Slate** | `seamline-video-slate-1920x1080.png` | Full HD `1920x1080` title/closing card with broadcast-safe margins |
| **Video Corner Bug / Lower-Third Overlay** | `logo-emblem-transparent-1024.png`, `logo-lockup-dark-transparent-2400.png` | True RGBA transparent PNGs ready to drop over footage in CapCut/Premiere/DaVinci |
| **Presentation Slides (Light Deck)** | `seamline-presentation-cover-light-1920x1080.png`, `logo-lockup-light-transparent-2400.png`, `logo-stacked-light-transparent-1200.png`, `logo-emblem-transparent-1024.png` | `16:9` `#f3f2ee` cover slide + transparent PNGs cleanly crisp over white/cream slides |
| **Presentation Slides (Dark Deck)** | `seamline-video-slate-1920x1080.png`, `logo-lockup-dark-transparent-2400.png`, `logo-stacked-dark-transparent-1200.png`, `logo-emblem-transparent-1024.png` | `16:9` `#0b1218` cover slide + transparent PNGs cleanly crisp over navy/charcoal slides |
| **Vector Master Files** | `seamline-emblem-dark.svg`, `seamline-emblem-transparent.svg` | Editable master geometry (`512x512` viewBox) |
| **Optional AI 3D Alternate** | `seamline-studio-emblem-3d-ai.jpg` | AI-generated studio-rendered emblem variation; disclose as AI-generated imagery if included in Space Apps submission media |
